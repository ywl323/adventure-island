# Adventure Island Sound Resources

Place your audio files here with the following names:

## Background Music (BGM)
- bgm_world1.mp3 — World 1 (Green Hills / Tropical)
- bgm_world2.mp3 — World 2 (Jungle)
- bgm_world3.mp3 — World 3 (Volcanic)
- bgm_world4.mp3 — World 4 (Final Island)
- bgm_boss.mp3 — Boss battle
- bgm_final_boss.mp3 — Final boss (Dark Dragon God)
- bgm_gameover.mp3 — Game over
- bgm_menu.mp3 — Menu screen

## Sound Effects (SE)
- se_jump.mp3 — Player jump
- se_coin.mp3 — Collect coin
- se_powerup.mp3 — Collect power-up
- se_hurt.mp3 — Player takes damage
- se_enemy_death.mp3 — Enemy defeated
- se_boss_hit.mp3 — Boss takes damage
- se_level_complete.mp3 — Level completed
- se_button.mp3 — UI button tap
- se_game_over.mp3 — Game over

Note: All files should be .mp3 format. Game will run without these but without sound.
